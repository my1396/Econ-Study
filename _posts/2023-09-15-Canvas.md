**Two types of quizzes:**

- 🔥 <span class="env-green">Assignment Quizzes</span>: show in grade book, can be graded, and students can see their results
  - [**Speed Grader**](#Speed-Grader) is enabled; can give feedback to individual students through submission comments; students can also send messages; → Easy to jump btw students; support rich text comments (equations). 
  - Students can send messages through comments. → Allow communication between students and graders.

- Practice Quizzes
  - Not shown in grade book by design. But you can still grade them.
  - Can see **Quiz Statistics** and **Moderate This Quiz**. → Hard to navigate btw students; support only plain text comments. → Not convenient to give feedback.
  - Students cannot send messages through comments. → One-way communication from graders to students.

--------------------------------------------------------------------------------

Q: What's the differences between <span class="env-green">**New Quizzes**</span> and Classic Quizzes? \
A: New Quizzes is supposed to have more features, such as screen calculator, but it is still in beta. You need to configure settings for each question... And it takes *forever to load* (it re-builds every time you open it). → Need some patience with New Quizzes; in exchange for better integration with [Item Banks](#item-banks), Stimulus question type.


New Quizzes are the trend anyways, so start using it now. 
It will support more features and be more robust in the future as it is under development.
By contrast, Classic Quizzes are stable but will be deprecated in the future.


Same logic everywhere. It's a trouble to migrate from an old version you are used to to a new version. 
You need to spend time to learn the new version, but <span class="env-green">it is worth it in the long run.</span> 👍

Q: What good is New Quizzes?

- Can shuffle questions whereas Classic Quizzes only support shuffle answers.
- Support <span class="env-green">**Stimulus**</span> question type (a passage followed by multiple questions).
  
  More [question types](https://cteresources.bc.edu/documentation/building-a-new-quiz/) are supported in New Quizzes.

  [How do I insert stimulus content in New Quizzes?](https://community.instructure.com/en/kb/articles/661063-how-do-i-insert-stimulus-content-in-new-quizzes)

- Only **New Quizzes** support the option "<span class="env-green">Do not count this assignment towards the final grade</span>." → In Classic Quizzes, you choose "Practice Quiz" to achieve the same effect.

See [HERE](https://www.usu.edu/teach/help-topics/canvas/new-quizzes) for a side-by-side comparison of Classic and New Quiz features.

## Question Banks

Question Banks are re-named as "<span class="env-green">**Item Banks**</span>" in New Quizzes.

Use Item Banks to mange quizzes, they are available across courses. So you don't need to copy quizzes from one course to another. You can just add questions from the Item Banks to your quizzes.


--------------------------------------------------------------------------------

A common scenario is that you have a quiz and you want to add it to an Item Bank.

1. Export the quiz as a QTI ZIP file. 
   
   Settings > Export Course Content
   
   <img src="{{site.baseurl}}/images/canvas export quiz to qti.png" alt="" style="display: block; margin-right: auto; margin-left: auto; zoom:80%;" />

   Choose "Quiz" in Export Type > Select the Quizzes you want to export > Click "Create Export"

   When the export is done, click "New Export" link to download the QTI ZIP file.

   <img src="{{site.baseurl}}/images/canvas content exports.png.webp" alt="" style="display: block; margin-right: auto; margin-left: auto; zoom:80%;" />

2. Import the QTI ZIP file into an Item Bank.
   
   <img src="{{site.baseurl}}/images/canvas import content.png" alt="" style="display: block; margin-right: auto; margin-left: auto; zoom:80%;" />

3. Add the questions from the Item Bank to your quiz.
   
   <img src="{{site.baseurl}}/images/canvas quiz from item banks.png" alt="" style="display: block; margin-right: auto; margin-left: auto; zoom:80%;" />

Q: I have two sub-quizzes, I want to combine them into one quiz and add them to an Item Bank. How can I do that?  
A: Following the steps below:

1. **Export the two quizzes as QTI packages.** See [export-quiz](#export-quiz).
2. **Import the QTI ZIP back into the course content.**
   
   Go to "Settings" > "Import Course Content" > From the "Content Type" dropdown, select .QTI Zip File and select the ZIP file > Click "Import".

   Now the two quizzes can be searchable when you create a new quiz.
3. **Combine the two quizzes into one quiz.**
   
   Create a new quiz, then go to "Questions" tab > Click "Find Questions" > Select the two quizzes you just imported > Click "Add Questions".
4. **Add the new combined quiz to an Item Bank.**
   
   <ol type="pa">
   <li> Export the new combined quiz as a QTI ZIP file. </li>
   <li> Import the QTI ZIP file into the Item Bank. <br/>
      
      Go to "Item Banks" > Click the three dots <code>...</code> at the top > Click "Import Content" > Select the QTI ZIP file of the combined quiz > Click "Import".
   </li>
   </ol>

> You <span class="env-orange">cannot</span> load two sub-quizzes using the QTI ZIP file in step 1 directly into an Item Bank. Only the first quiz will be imported and the item bank will be re-named as the first quiz's name. 
> 
> So you have to first combine the two quizzes into one quiz, then import the combined quiz into an Item Bank.

ref: [How to Combine Classic Quizzes in Canvas](https://help.ithaca.edu/TDClient/34/Portal/KB/ArticleDet?ID=1632)

Q: What is a Question Group?  
A: A Question Group is a collection of questions that can be added to a quiz. When a Question Group is added to a quiz, <span class="env-green">a specified number of questions are randomly selected</span> from the group for each student taking the quiz. This allows for greater variability in the questions presented to each student, which can help reduce cheating and improve assessment reliability.

> If you need your questions to appear in a specific order, do NOT use Question Groups.

## Edit math equations on Canvas


**Tips:**

- Short symbols: Use `\(...\)` for inline equations and `$$...$$` for block equations. The equations won't be displayed live. <span class="env-green">When your focus is moved out of the text field</span>, your LaTeX code will be rendered.

- Complex formulas: Select ‘Directly Edit LaTeX’ in the Maths Editor to create complex equations. A **preview** of what will be displayed is shown underneath the LaTeX code.


**A nice Tutorial how to edit latex on Canvas**

<https://ready.msudenver.edu/self-help-tutorials/accessibility/use-mathjax-and-latex-to-display-equations-in-canvas/>

1. Type the appropriate Delimiter to signal that the equation should be rendered in LaTeX.

   - **`\(`** and **`\)`** should be used for equations that are meant to be displayed **inline** with text.

     When edit quiz questions, use `\(...\)` as delimiters in LaTex. This saves time when you copy and paste from LaTex to Canvas.

   - **`$$`** should be used for equations that are meant to be displayed in separate **blocks**.

2. Type  the Equation between the delimiters.

   - Ex: `\(2+2=4\)` for inline text or `$$2+2=4$$` for block text

3. *Click* **Save** for whatever text field you are working in. 

   The text field won't render the eqn. immediately for you. 
   Only **after** you exit the text field and preview the question, the eqn will show up properly.

4. *Check* that the **Equation** is being displayed correctly.



**Can also insert a file/image** into the field box.

<https://support.inspera.com/hc/en-us/articles/360043210312-Insert-file-in-questions>

## Files

When replacing a file in Canvas, first change the name of the new file to be exactly the same as the old file. Then upload the new file. This way, the old file will be replaced and all links to the old file will still work.

- Otherwise, you will have to delete the old file and then re-add the new files to the corresponding modules.
- The display name under modules will stay the same as the old file name. The display name points to files. When you replace a file, the display name will not change. 

Q: What is the difference between display name and file name? \
A: Display name is for indicating the content of the file. It can be any name you want as it is only a text field. File name, on the other hand, is the actual name of the file; cannot contain special characters like `:`.

- You don't have to change the file name when uploading a file. Just change the display name. This way, you can keep the file name consistent with your local version, and you can replace it without changing the file name.

Q: How to specify the visibility time for a file? \
A: Schedule visibility. 

Go to Files, Click the three dots next to the file you want to schedule (Under Actions column), then click "<span class="env-green">**Edit Permissions**</span>", Under Available, choose "**Schedule availability**". 

<img src="https://media.screensteps.com/image_assets/assets/009/399/163/original/26ecd777-f53c-48f0-af67-7f96b71cc447.png" alt="" style="display: block; margin-right: auto; margin-left: auto; zoom:80%;" />

Then you can add the file to corresponding module. The file will only be visible during the scheduled time.

ref: [How do I restrict files and folders?](https://community.instructure.com/en/kb/articles/662851-how-do-i-restrict-files-and-folders)
